How the AI step works

When you pick a route and a style, Amosix sends your selections to a foundation model on AWS Bedrock. The model returns a structured animation plan — camera keyframes, waypoint order, zoom levels, bearings, and pacing — which our native MapLibre and MediaCodec engine renders into your final 60fps MP4.

  • Selection in: your chosen countries, stops, and style preset.
  • AI planning: Bedrock converts intent into a structured keyframe plan.
  • Native render: the on-device engine turns that plan into video.

This feature is currently in development and will roll out during closed beta.

DEVELOPER VERIFICATION & TECHNICAL DEEP DIVE

Native codebase architecture & engine specs.

Extracted directly from our Android repository (com.amosix.mapanimator) for technical review, demonstrating real low-level hardware integration and zero mock implementation.

01 MAP ENGINE & STYLES

MapLibre GL Native & Unlimited Map Style Support

Amosix is built from the ground up on the MapLibre GL Native SDK (v11.5.2), taking advantage of C++/OpenGL vector tile rendering and extensive style customization:

  • Universal MapLibre Spec Support: Compatible with all MapLibre and Mapbox GL JSON style specifications, allowing seamless integration of MapTiler Satellite, Hybrid, Streets, Topo, and custom vector styles.
  • 3D DEM Terrain Elevation: Renders digital elevation model (raster-dem) terrain layers for realistic 3D mountain flyovers, relief shading, and camera pitch angles up to 60°.
  • Custom Style Endpoint Loader: Loads online vector tile URLs, offline mbtiles databases, and custom GeoJSON feature collections dynamically at runtime.
02 MODULE STRUCTURE

Package Organization (com.amosix.mapanimator)

The Android application is structured into isolated, testable Kotlin packages designed for high-performance offline animation processing:

  • com.amosix.mapanimator.timeline: Controls keyframe state vectors, Catmull-Rom spline calculations, and timeline scrubbing logic.
  • com.amosix.mapanimator.export: Manages offscreen MapSnapshotter FBO rendering, deterministic stepping clocks, and MediaCodec H.264 video encoding.
  • com.amosix.mapanimator.overlay: Handles GeoJSON polygon boundary parsing, dynamic polyline progress calculation, and animated marker placement.
03 OFFSCREEN PIPELINE

Deterministic Anti-Flicker Frame Capture

Standard screen recorders suffer from UI stutter and tile loading pop-in. Amosix bypasses the Android View hierarchy using a hardware-isolated render loop:

  • Deterministic Time Stepping: Frame timestamps advance strictly by 1 / TargetFPS (e.g., 16.66ms for 60fps), completely decoupled from real-time execution speeds.
  • Tile Completion Callbacks: Each snapshot waits for MapLibre GL Native's onSnapshotReady event to guarantee all vector geometry and raster tiles are fully rendered before frame capture.
  • Zero White-Tile Artifacts: Ensures 100% frame completeness even under heavy 4K satellite texture workloads.
04 MATH & MOTION BLUR

180° Shutter Temporal Accumulation

To achieve cinematic fluidity during fast map flyovers, Amosix implements hardware multi-sampling without artificial post-processing filters:

  • Temporal Sub-Framing: Evaluates camera spline trajectories across 4 sub-frame intervals within each target frame's shutter interval.
  • 180° Shutter Angle: Blends sub-frame buffer passes on GPU surface textures to mimic physical film camera exposure behavior.
  • Catmull-Rom Splines: Interpolates camera latitude, longitude, altitude, bearing (0-360°), and pitch (0-60°) through continuous 3D control points.
05 HARDWARE ENCODING

Zero-Copy MediaCodec & MediaStore Pipe

Direct hardware video encoding pipeline utilizing native Android media APIs for maximal efficiency and low memory footprint:

  • EGL Surface Direct Feeding: OpenGL FBO texture buffers pass directly into MediaCodec input surfaces via hardware registers.
  • H.264 / HEVC Encoding: Configurable bitrates (up to 50 Mbps) and resolutions (720p, 1080p, and native 4K).
  • MediaStore Storage API: Writes finalized MP4 containers to system Movies/MapAnimator storage using Android 10+ scoped storage APIs.
