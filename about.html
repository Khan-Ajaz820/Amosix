ABOUT US

Building cinematic maps for mobile.

Amosix is an independent software project focused on one idea: bringing studio-quality map flyover animations to the phone in your pocket. What used to require desktop motion-graphics tools and plugins now runs natively on Android, rendering directly on the device GPU.

What we do

We build a native Android engine that turns map journeys into smooth, exportable video. Users frame a camera path, draw routes, and highlight regions, then export a hardware-encoded 60fps MP4 — all on-device, without a render farm or a laptop.

How it's built

Amosix is built from the ground up on the MapLibre GL Native engine, using the MapTiler map style as its default source. The rendering pipeline uses Android's MediaCodec and MediaMuxer APIs for hardware video export, with a deterministic frame-capture loop that avoids the stutter and missing tiles common to screen recording.

Where AI fits

We're developing an AI animation builder that lets users create a flyover by simply selecting the countries or regions they want to travel between. Those selections are sent to a foundation model on AWS Bedrock, which returns a structured animation plan that our native engine renders into video. The goal is to make cinematic map animation accessible to people who aren't motion designers.

Where we are

Amosix is currently in active development and closed beta. We're refining the engine, expanding style support, and building out the AI feature ahead of a wider release.
